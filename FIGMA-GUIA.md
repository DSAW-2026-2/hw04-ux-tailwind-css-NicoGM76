# Guía para los wireframes de Figma

El archivo `figma-link.txt` debe contener el enlace PÚBLICO del archivo de Figma.

## Pantallas recomendadas

Crea como mínimo estas pantallas manteniendo el mismo estilo visual:

1. Landing / Inicio
2. Vista Cliente
3. Vista Vendedor
4. Vista Administrador

## Contenido por pantalla

### Landing / Inicio
- Barra de navegación
- Logo / nombre MicroERP Farmacia
- Buscador
- Categorías
- Productos destacados
- Acceso de usuario

### Vista Cliente
- Buscador
- Filtro por categoría
- Filtro por nombre
- Filtro por valor
- Listado de productos

### Vista Vendedor
- Tabla o tarjetas de inventario
- Stock
- Valor
- Código
- Categoría
- Ubicación

### Vista Administrador
- Listado de productos
- Botón Crear
- Acción Editar
- Acción Eliminar
- Formulario de producto

## Estados

Para fortalecer el entregable, crea los siguientes estados en las pantallas principales:

- Estado normal / con datos
- Estado vacío / sin resultados
- Estado de error

## Antes de entregar

1. En Figma, pulsa **Share**.
2. Cambia el acceso a **Anyone with the link can view**.
3. Copia el enlace.
4. Abre `figma-link.txt`.
5. Reemplaza `PEGA_AQUI_EL_ENLACE_PUBLICO_DE_TU_FIGMA` por el enlace.
6. Guarda el archivo antes de hacer `git add`.
