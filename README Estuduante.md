# HW04 — UX + Tailwind CSS

Repositorio de la actividad **UX + Tailwind CSS**.

## Entregables

- `index.html`: landing page reconstruida con clases utilitarias de Tailwind CSS.
- `figma-link.txt`: enlace público a los wireframes realizados en Figma.
- `BITACORA-IA.md`: registro del uso de IA para la selección y ajuste de la paleta.
- `FIGMA-GUIA.md`: guía de apoyo para completar los wireframes.

## Dark mode

El botón de modo oscuro:

- Alterna la clase `dark` en el elemento `<html>`.
- Guarda la elección en `localStorage` con la clave `theme`.
- Recupera la preferencia al volver a cargar la página.
- Si no existe una preferencia guardada, toma como referencia la preferencia del sistema.
